刷题防线 · 三种画风

同一场景（掩体 + 己方坦克 + 三种敌人 + 基地），只换画法和配色
A · 街机像素ARCADE
深色底 + 硬边像素 + 扫描线。墙是橙红砖块，坦克是黄铜色。
优点：经典、有街机质感，开发最快。
缺点：和笔记站的纸本风完全割裂。
B · 战术指挥屏TACTICAL
军绿底 + 网格 + 雷达扫描。己方是青色箭头，敌方是红色菱形，墙是暗色块。
优点：和「防线」「战术」主题最贴，高级感强，自适应性好做。
缺点：偏冷，少了点娱乐性。
C · 纸本作战图PAPER
米色纸底 + 铅笔排线 + 手绘线条。像作战参谋在笔记本上画的推演图。
优点：和笔记站视觉统一，从笔记点进游戏不会「跳戏」。
缺点：动效空间小，快速移动时不如像素清晰。
